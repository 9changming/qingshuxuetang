智读 · PDF 智能学习平台 — 发布包
================================

一、Linux 用户（本机已编译）
----------------------------
直接运行：
  chmod +x 智读_linux_x64
  ./智读_linux_x64

浏览器会自动打开 http://127.0.0.1:8765
数据保存在可执行文件同目录的 data/ 下。


二、Windows 用户（生成 .exe）
----------------------------
本次优化针对 windows_build 中提供的 Python 源码；Linux 预编译程序因未附源代码而保持原样。

1. 安装 Python 3.10 或更高版本（安装时勾选 Add Python to PATH）
   下载：https://www.python.org/downloads/

2. 进入 windows_build 文件夹，双击运行：
     build_exe.bat

3. 完成后在 windows_build\release\智读.exe
   将 智读.exe 拷到任意目录双击即可使用。

四、本机智能助手（Ollama）
--------------------------
1. 安装并启动 Ollama：https://ollama.com/download
2. 在终端下载模型，例如：
     ollama pull qwen2.5:7b
3. 启动智读后，在学段页面右上角选择已安装的模型即可对话。
   默认连接地址：http://127.0.0.1:11434
   如 Ollama 使用其它本机端口，可设置环境变量 ZHIDU_OLLAMA_URL。
4. 助手可读取选中 PDF 的前 10 页（最多 16000 字符）；扫描件无法直接识别。
   直接运行源码前，请在 windows_build 目录执行：
     python -m pip install -r requirements.txt
5. 上传 PDF 后可点击“根据文件内容识别分类”，由所选 Ollama 模型建议学段、学科、年级和新增主题；确认上传前可自行修改。
6. 学段首页会显示已上传资料中的主题分类。选中平台内 PDF 后，点击“总结资料”可生成内容概述、核心要点和复习建议（最多分析 120 页）。
7. 在学习笔记中选择平台资料并点击“插入引用”，引用资料会随笔记一起保存；每篇笔记最多引用 20 份资料。

五、公开 PDF 归档
----------------
管理员进入“资源审核”，点击“归档可下载公开 PDF”。
平台仅保存白名单来源可验证为 PDF 的文件；外部网页和不可下载资源仍保留原站链接。
归档文件保存在程序同目录的 public_pdfs/ 下。


六、说明
--------
- SQLite 使用标准库；源码运行 PDF 正文问答需安装 requirements.txt 中的依赖
- 首次运行自动初始化
- 上传的 PDF 文件（最大 50 MB）保存在程序同目录的 uploads/ 下
- Ollama 模型需单独安装；推理在本机运行，不需要云端 API Key
- 按 Ctrl+C 或关闭窗口可停止服务
