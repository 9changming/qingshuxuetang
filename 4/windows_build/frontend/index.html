关于智读

智读是面向幼儿园至大学的 PDF 智能学习平台，聚合国家中小学智慧教育平台、OpenStax、MIT OCW 等真实开放教材与官方资源，支持跳转原站阅读，并提供本地智能问答、收藏与笔记。

主要功能

  • 五大学段资料浏览与学科筛选
  • 学习助手问答（连接本机 Ollama 模型）
  • 管理者可将来源明确的公开 PDF 存档到平台
  • 收藏、最近浏览、全局搜索
  • 学习笔记（云端同步）
  • 上传资料与管理者审核
  • 深色模式

快捷键

  • / 或 Ctrl+K 打开全局搜索
  • Esc 关闭弹层
  • 阅读器内 ← → 翻页

账号说明

访客输入昵称即可使用；管理者由系统分配账号密码。数据通过后端安全存储。
